# Vertex diagrams

The English and German Mermaid sources describe the public edge, Fleet delivery
and replicated storage in three complementary diagrams. The delivery diagram
also has a vertical mobile variant. They contain no credentials or private
addresses. Regenerate the committed SVGs with `npm run diagrams:vertex`;
the shared renderer and browser requirements are documented in the PDCD Mail
diagram README. Keep the two languages, accessible descriptions and image
sizes aligned.
