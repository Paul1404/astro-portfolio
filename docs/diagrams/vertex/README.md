# Vertex diagrams

The English and German architecture and preview Mermaid sources describe the public edge, Fleet and
replicated storage as a simplified architecture. They contain no credentials or
private addresses. Regenerate the committed SVGs with `npm run diagrams:vertex`;
the shared renderer and browser requirements are documented in the PDCD Mail
diagram README. Keep the two languages, accessible descriptions and image
sizes aligned.

The preview SVGs are exported to localized WebP assets on a light 1600 by 900
canvas for project cards. They remain diagrams, not product screenshots.
